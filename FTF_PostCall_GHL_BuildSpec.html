Triggers — This Workflow Needs TWO Trigger Conditions (OR logic)
  • Trigger 1: Tag Added → Tag = attended-sunday-call
  • Trigger 2: Tag Added → Tag = aj-called
⚠ The no-show path (Path C) is handled inside this workflow via a branch. You don't need a separate trigger for no-shows — the Sunday Call sequence will enroll the producer into this workflow on Monday morning if they didn't attend. That enrollment fires without the attended-sunday-call tag, which the branch detects. See Step 1 below.
Alternative approach (simpler): Have the Sunday Call sequence enroll all producers into this workflow — both attendees (with tag) and no-shows (without tag). Then branch at Step 1.
Workflow Steps — No-Show Branch (Path C) Runs only if no attended-sunday-call tag

Branch — Did They Attend?
IF/ELSE Branch
In GHL: Add action → If/Else

Condition: Contact has tag attended-sunday-call OR has tag aj-called

YES branch (attended or AJ-called): → Skip to Step 4 (Touch 1 — Welcome Email). Send immediately.

NO branch (no-show): → Continue to Step 2 below.
⚠ In GHL, branches don't "jump" — structure the NO path to flow downward naturally, and end the NO path before Touch 1 fires. Alternatively, build no-show handling in a separate workflow and enroll from Sunday Call sequence separately. See bottom of doc for both approaches.

Exit Condition — How to Remove Them Early
A producer who starts their store must exit this sequence the moment they do. Here's how to set that up:

Option A — Goal (Recommended):
In GHL workflow settings → Goals → Add a goal:
Contact field: contact.producer__status
Condition: equals Draft OR equals In Review OR equals Approved
When the goal is met → the contact exits the workflow immediately and is enrolled in the Onboarding Setup sequence.

Option B — Tag-Based:
If Option A isn't possible with your setup: AJ or the system adds tag store-setup-started when a producer begins their profile → use a Remove from Workflow action in another workflow triggered by that tag.

After Published:
Skool invite fires from the Producer: Published workflow (workflow #5 in your existing pipeline), NOT from this sequence. Open that workflow and add a Send Email action with the Skool link: https://www.skool.com/from-the-farm-producers-5253/about

Common GHL Mistakes to Avoid
  • Don't use "Wait X days" when you mean "Wait until next Monday" — use the specific day/time wait for the no-show step.
  • SMS must be plain text — no HTML tags, no formatted links. Just paste the full URL.
  • GHL merges variable names with contact fields. Use {{contact.first_name}} — NOT [First Name] — in the actual GHL editor. The [First Name] in this doc is a placeholder for the variable.
  • Set "Allow Re-entry" to OFF. If a producer registers for multiple Sunday calls, they should not run this sequence twice.
  • Check "Stop on Response" is ON — if they reply to an email or SMS, the sequence should pause and AJ handles the conversation manually.
  • Emails are HTML in GHL — keep the formatting simple. Plain text style (no heavy headers or buttons needed — the copy is the conversion tool).
No-Show Branch Architecture — Two Options
Option A — Single Workflow (Recommended for simplicity):
One workflow, enrolled by Sunday Call sequence for everyone (attendees + no-shows). Branch at Step 1: attended → skip to Touch 1 immediately. No-show → wait until Monday → bridge email → wait 1 day → Touch 1.

Option B — Two Separate Workflows:
Workflow 1: "Post-Call — Attended" — triggered by attended-sunday-call OR aj-called tag. Goes straight to Touch 1.
Workflow 2: "Post-Call — No-Show" — triggered Monday by Sunday Call sequence if no attended-sunday-call tag. Sends bridge email → wait 1 day → enrolls into Workflow 1 at Touch 1.

Option A is simpler to manage. Option B is cleaner if GHL's branching is difficult to configure.
Recording Link — Weekly Process for AJ
The No-Show Bridge email needs a recording link from the previous Sunday's call. Two ways to handle this:

Option A (Manual, simple): AJ updates the No-Show Bridge email template in GHL each Monday morning with that week's Zoom recording link. Takes 2 minutes.

Option B (Custom field): Create a GHL custom field sunday_call_recording_url. AJ or assistant updates the field each Monday. The email uses {{contact.sunday_call_recording_url}}. Cleaner but requires field setup.

Either way, the workflow fires Monday at 9am — AJ needs to have the link ready before then.
